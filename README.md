# Asterisk PBX Lab with Docker

Complete VoIP lab setup using Asterisk 22.6.0 running in Docker.

## Features

- ✅ SIP Registration (3 users: 1001, 1002, 1003)
- ✅ Direct Calling between users
- ✅ Voicemail with retrieval (*97)
- ✅ Conference Bridge (extension 700)
- ✅ Call Queues (Support: 800, Sales: 801)
- ✅ Music on Hold
- ✅ Echo Test (extension 600)

## Prerequisites

- Ubuntu 22.04+ or similar Linux distribution
- Docker and Docker Compose installed
- Network: 192.168.100.0/24 (or modify IP addresses)
